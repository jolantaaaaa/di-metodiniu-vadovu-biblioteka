# DI metodinių vadovų biblioteka

Statinė GitHub Pages svetainė. Visi PDF yra kataloge `pdf/`, viršeliai `assets/`.

## Publikavimas
1. GitHub sukurkite viešą saugyklą, pvz., `di-metodiniu-vadovu-biblioteka`.
2. Įkelkite visus šio archyvo failus ir katalogus į saugyklos šaknį.
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. Svetainė bus pasiekiama adresu `https://JUSU-VARDAS.github.io/di-metodiniu-vadovu-biblioteka/`.

**Svarbu:** GitHub Pages publikuoja PDF viešai.
